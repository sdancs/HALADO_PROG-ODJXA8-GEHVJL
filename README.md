Parkolóhely felismerő rendszer

A projekt célja:
Python alapú alkalmazás, amely parkolókról készült képek alapján megpróbálja a foglaltságot meghatározni.

Tervezett funkciók:
-kép betöltés
-járművek felismerése
-szabad helyek meghatározása
